# Udemy React App

This repository contains explorations of React, Next.js, and TypeScript through hands-on practice projects. Each top-level folder is a standalone project covering a different part of the stack, from a simple React crash course to more advanced Next.js patterns. `dummy-backend` provides a small mock API used by some of the frontend projects for practice with data fetching. The code here is exploratory and course-driven rather than production-ready. It exists mainly as a personal reference and playground while learning these technologies.
